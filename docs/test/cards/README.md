# Test cards and data sheets — DBF-TP-001 rev B

Printable Markdown. Flight test cards (one per flight test) and data sheets for component, structural and ground tests. Fill in on paper or in a text editor, then file a report with REPORT-TEMPLATE.md and update ../test-matrix.csv.

| File | Tests |
|---|---|
| FTC-F01.md … FTC-F13.md | Flight tests F01–F13 (TEST-PLAN.md §9.5); F09 is the stall determination, F13 the gear-fairing A/B |
| DS-C01.md | Printed hole and bore coupon |
| DS-C02-C03.md | Insert torque-out, pull-out, floor crush (C02, C03, C04) |
| DS-C05.md | Tube receipt and joiner fit |
| DS-C06-C07.md | Thrust-stand calibration and motor thrust curves |
| DS-C08-C09-C10.md | Hover-duty heat, pusher curve, stopped prop |
| DS-C11.md | Battery capacity, sag, internal resistance |
| DS-C12.md | Servo torque and centering |
| DS-S01.md | Wing proof load |
| DS-S02-S04.md | Boom stiffness, modal, clamp slip, motor mount (S02–S05) |
| DS-S06.md | Landing-gear drop |
| DS-G01.md | Weight and balance with and without ballast (G01, G09) |
| DS-C16-C17-S10.md | F05 / counterbore first article, joiner slip fit and stops, ballast retention |
| DS-G03.md | Tied-down run, harness heating, vibration, compassmot |
| REPORT-TEMPLATE.md | Test report template |

Tests without a dedicated sheet (C13–C15, S07–S09, E-series, G02, G04–G08, I-series; SITL evidence for E05/E06 is in firmware/sitl/results/) use REPORT-TEMPLATE.md with the pass criteria from TEST-PLAN.md.
